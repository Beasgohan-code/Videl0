# VYRON frontend attribution

The following VYRON frontend patterns were adapted for Videl's existing music experience: generated album artwork (`VyronCover`) and deterministic waveform seeking (`VyronSeek`). They are integrated into Videl's UI and use Videl's existing music search and playback path; no VYRON backend code is included.

Source: https://github.com/Beasgohan-code/VYRON
