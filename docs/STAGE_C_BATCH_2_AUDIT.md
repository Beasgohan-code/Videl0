## Test-first fixes completed in this continuation

1. Added `tests/test_music_picker_security.py`. The initial four tests failed: any member could cancel another user's picker; owner bypassed requester binding; callback chat was not tied to cache origin; and missing actor was accepted on cancel. Updated the callback; all four regressions now pass, along with existing `/playnext` and picker cleanup tests.
2. Added `tests/test_cplay_media.py`. Both tests initially failed: arbitrary PDF documents and 201 MiB media reached `get_messages`/download. Corrected unreachable document validation, added the existing 200 MiB limit and fail-closed empty-download handling. Both regressions pass.
3. Added test-first duration-limit regressions for `/cplay` search/direct URLs, `/play` local media, YouTube playlists, saved playlists and AutoPlay. The uncovered cases failed before the filters and pass afterward; exactly-at-limit cplay remains admissible. Playlist responses distinguish duration-limit omissions from queue-cap omissions.
4. Added `tests/test_music_picker_cache.py` for stale-entry pruning and FIFO capacity eviction.
5. Added `tests/test_lyrics_privacy.py`; it failed when provider exceptions echoed the full query URL and now passes with exception-class-only logging. `tests/test_lyrics_provider.py` first reproduced a crash on malformed LRCLIB rows; malformed rows are now skipped safely.
6. Added `tests/test_downloader_callbacks.py`; unknown and extra `dl:` callback payloads now receive an answer without triggering a content edit.

## Continuation — defensive fixes and privacy-safe provider logs

AutoPlay now emits a generic warning on search failure rather than logging user query variations or provider exceptions that may contain URLs or credential-like parameters. Missing/null provider titles fall back to `Unknown`. Malformed/non-dictionary playlist rows and non-list playlist payloads are skipped safely so one bad row does not block later valid tracks (`tests/test_autoplay_safety.py`). The `/queue` read path filters malformed non-dictionary entries without mutating playback state. Offline regressions cover each case; provider behavior remains mocked.
