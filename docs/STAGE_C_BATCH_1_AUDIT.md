## Test-first changes in this batch

1. Added regression tests first; the initial six reminder tests failed against the old behavior (group list exposed and button had no clear handler). Implemented the private-list boundary and real private actor-scoped clear action, then added repeated-click coverage; all 7 reminder tests passed.
2. Added concurrent AFK handler test first; both tests failed because the old code used a non-atomic `find_one` then `update_one`. Replaced it with a cooldown-conditional atomic Mongo update; 2 tests passed.
3. Added missing-actor `/inbox` test first; it reproduced an `AttributeError`. Added a fail-closed identity check; 1 test passed.

Combined focused validation (source/test-only, mocked/offline): **143 passed, 722 subtests passed** across command registry, command UI/presentation/navigation, accessible help, bot API/experience, stats, member data/preferences, Telegram helpers and the three Batch 1 regression files. Live Telegram, MongoDB, staging and device validation were not performed.
