## ⬩ ᴅᴇᴘʟᴏʏ — ᴘʀᴏᴅᴜᴄᴛɪᴏɴ ◍

```bash
git clone https://github.com/Beasgohan-code/Videl0 && cd Videl0
cp sample.env .env
# fill required: API_ID API_HASH BOT_TOKEN STRING_SESSION MONGO_DB_URL OWNER_ID
nano .env
python main.py                  # Flask health on :$PORT (10000) + watchdog
# Docker (single PORT — videl owns it, no clash):
docker build -t videl:perfect . && docker run --env-file .env -p 10000:10000 videl:perfect
# Plus keep-alive on VPS: docker run -e KEEPALIVE_PORT=8000 -p 10000:10000 -p 8000:8000 ...
# Render: Uses render.yaml (healthCheckPath /health)
```
